Understand the issue correctly and then start working on this. I want the best possible solution for this, but with the minimum code possible. The code should not be bloated, and it should be clearly solving the problem fully.

Add critical test cases which are going to check this for any kind of variations in the future. If it's a new feature addition, then also check for that. The tests should also not be bloated.

After you are done creating the thing, commit and push, and then check for the peer review bots. Fix the bot comments and check if they are right or not. Use your best judgment to touch the code according to their comments or not. After all this is done, merge it.
